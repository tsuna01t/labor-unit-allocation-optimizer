# 勞作單元分配小幫手
依「目標總收益／商品單價」換算目標產量，再根據各資源合成需求、基礎產出、單元效率與投入上限，將總勞作單元做貪婪式分配，使最慢的資源路徑盡可能提前。
---
# 使用方法

## 1.基本參數填寫
目標總收益：想賺到的琅

商品單價：要賣的商品當前價格(漲幅最高的)

總勞作單元：目前擁有的勞作單元數量

![圖](https://i.meee.com.tw/SkdD4tN.png)
![圖](https://i.meee.com.tw/6G15p23.png)

## 2.資源資料填寫
合成需求：填寫要賣的商品材料比例

基礎產出：基礎產出+富集點產出，若有多個採集場須加總

單元效率：每一勞動單元產出

投入上限：採集場可入駐勞動單元數量，若有多個採集場須加總

當前庫存：目前擁有的材料數量

填寫完後按下計算最佳同步分配方案按鈕
